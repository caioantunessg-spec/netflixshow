# netflixshow

## Principais Descobertas
- A Netflix adiciona majoritariamente conteúdo recém-lançado: metade do
  catálogo entra até 1 ano após o lançamento original (mediana = 1 ano).
- Identificada uma particularidade nos dados: alguns títulos têm
  `release_year` posterior à data real de adição, por conta de lançamentos
  em dezembro rotulados com o ano seguinte — tratado usando mediana em vez
  de média para evitar distorção.
